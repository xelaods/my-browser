プライバシーポリシー

My Browser・最終更新 2026年10月

My Browser は、あなたの閲覧データを開発者や第三者に送りません。データはすべてあなたのパソコンの中に保存されます。

パソコンの中に保存するもの

  • 開いていたタブ、お気に入り、プロフィール、設定
  • 閲覧履歴（URL欄の候補に使います。設定でオフにできます）
  • Cookie やログイン状態などのサイトのデータ（Chromium と同じ仕組みで保存します）
  • サイトに許可・ブロックした権限（カメラ、マイク、位置情報、通知など）
  • Chromeウェブストアから追加した拡張機能

シークレットタブで見たページの履歴・Cookie・キャッシュは保存されず、シークレットタブをすべて閉じると消えます。保存場所は「設定 → システム → データの保存場所」から確認できます。

外部に通信するもの

  • 見ているWebサイト：通常のブラウザと同じように、表示に必要な通信を行います。
  • 検索エンジン：URL欄や新しいタブで検索したとき、設定で選んだ検索エンジンに検索語を送ります。入力中の文字は送りません（候補はこのパソコンの履歴とお気に入りから出します）。
  • AIパネル：「要約」などのボタンを押したときだけ、表示中のページのタイトル・URL・本文（または選択した部分）を、AIパネルで開いているAIサービスの入力欄に貼り付けます。送信するかどうかはあなたが決めます。送信した内容の扱いは、そのAIサービスのプライバシーポリシーに従います。
  • 広告とトラッカーのブロック：数日に1回、ブロック用のリスト（EasyList・EasyPrivacy など）を GitHub からダウンロードします。閲覧したページの情報は送りません。
  • 拡張機能：拡張機能は Chromeウェブストアからダウンロード・更新します。追加した拡張機能は、それぞれのプライバシーポリシーに従います。
  • 自動アップデート：インストール版では、GitHub に新しいバージョンがあるかを確認します。送るのはアプリのバージョンなど更新に必要な情報だけです。設定でオフにできます。

送らないもの

  • 利用状況の統計（テレメトリー）やクラッシュレポートは送りません。
  • 広告目的のIDやトラッキングは使いません。

あなたが選べること

  • 閲覧履歴・Cookie・キャッシュは「設定 → プライバシー」からいつでも削除できます。
  • サイトの権限は、URL欄の鍵マークか「設定 → プライバシー」で変更できます。
  • 「トラッキングの拒否を伝える」をオンにすると、サイトに Global Privacy Control（GPC）を送ります。
