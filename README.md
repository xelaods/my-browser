# My Browser（Electron製・Arc風）

縦タブとAIサイドパネルを持つ、Chromiumベースのブラウザです。

## 起動
- **ふだん**：デスクトップかスタートメニューの「My Browser」をダブルクリック
- **はじめて使うPC・アップデートしたあと**：このフォルダの「セットアップ.bat」をダブルクリック（必要な部品の準備とショートカット作成をまとめて行います。Node.js が未インストールならダウンロードページが開きます）
- **ショートカットだけ作り直す**：「ショートカットを作成.bat」をダブルクリック
- 開発用に、コマンドプロンプトで `npm start` でも起動できます（初回だけ先に `npm install`）

## 画面の見方
- **上のタイトルバー**：左に「サイドバー切替・戻る/進む/再読み込み」、中央にURL欄、右に「ダウンロード」「設定」「AI」ボタンとウィンドウ操作
- **URL欄**：入力すると履歴・お気に入り・検索の候補が出ます（↑↓で選んで Enter）。左の鍵マークでサイト情報と権限、右に倍率（100%以外のとき）
- **左のサイドバー**：上から「お気に入り（アイコンのみ）」「固定タブ」「今日のタブ」「プロフィールの切り替え」（隠しているときは、画面の左端にマウスを持っていくとページの上に重ねて表示します。ページの幅は変わりません）
- **右**：AIパネル（右上の「AI」ボタンか Ctrl+E で開閉）

## 新しいタブとコマンドバー（Arc / Zen 風）
- **Ctrl+T** か「新しいタブ」を押すと、画面の中央に検索ボックスが浮かびます。入力して **Enter** したときに初めてタブができます（Esc で何も作らずに閉じる）
- 入力すると「検索・URL・開いているタブ・お気に入り・ブックマーク・履歴・操作」をまとめて探せます。開いているタブを選ぶとそのタブに切り替わります
- **Ctrl+K** はコマンドバー：「翻訳」「画面を分割」「タブを固定」「URLをコピー」「ライト／ダーク」などの操作を名前で探して実行できます（英語名でも検索可）。URLを選ぶと今のタブで開きます
- **Shift+Enter** で、選んだページを今のタブの横に並べて開きます
- Ctrl+Shift+N はシークレットタブ用の検索ボックスになります

## 画面分割（2〜4つ）
- Ctrl+K →「画面を分割」でページを選ぶ、タブを右クリック →「今のタブと並べて表示」、リンクを右クリック →「横に並べて開く」、検索ボックスで Shift+Enter
- クリックしたページが選択中になり（縁が濃くなります）、URL欄や戻る・ページ内検索はそのページに効きます
- サイドバーでは、並んでいるタブの左に線が付きます。解除はタブの右クリックか Ctrl+K →「画面分割を解除」

## リンクのプレビュー
- リンクを **Alt+クリック**（または右クリック →「プレビューで開く」）すると、タブを増やさずにページの上に大きく表示します
- 上のボタンで「タブで開く（そのまま移す）」「横に並べる」。外側をクリックか Esc で閉じます

## ページの翻訳
- 表示している言語と違うページでは、URL欄の右に翻訳ボタンが出ます。押すとページの中で訳文に置き換わり、もう一度押すと原文に戻ります（あとから読み込まれた部分も訳します）
- 右クリック → 「日本語に翻訳」、Ctrl+K →「このページを翻訳」でも使えます
- 標準は Google 翻訳です。設定 → 一般 →「翻訳」で DeepL（APIキーが必要）に切り替えられます。翻訳するときだけページの文章を送り、Cookie は送りません

## パスワード
- ログインすると「パスワードを保存しますか？」と聞きます（保存／このサイトでは保存しない）。シークレットタブや暗号化されていない http のページでは保存しません
- 保存したサイトでユーザー名やパスワードの欄をクリックすると候補が出て、選ぶと入力されます
- パスワードはOSの仕組み（Windows では DPAPI）で暗号化して、このPCの中だけに保存します
- 設定 →「パスワード」で一覧・表示・削除、Chrome や Edge から書き出したCSVの読み込みができます

## ほかのブラウザから読み込む
- 設定 →「読み込み」で Chrome・Edge・Brave・Vivaldi のブックマークと履歴を読み込めます（ブックマークバーの先頭はお気に入りにも入れられます）
- 履歴が読み込めないときは、そのブラウザを閉じてからもう一度
- 読み込んだブックマークは URL欄と Ctrl+K で検索できます

## プロフィールごとのログイン
- 設定 →「プロフィール」の「ログイン情報を分ける」をオンにすると、そのプロフィールは Cookie やログイン状態が別になります（仕事用と個人用で別のアカウントを使うなど）。新しく作ったプロフィールは最初からオンです
- ログイン情報を分けたプロフィールでは、Chrome拡張機能は動きません（拡張機能は「メイン」などログインを共有しているプロフィールで動きます）
- AIパネルはどのプロフィールでも共通のログインです

## セキュリティとプライバシー
- **サイトの権限**：カメラ・マイク・位置情報・通知などは、サイトが求めたときにページ右上で「許可／ブロック」を聞きます。鍵マークか設定から変更できます
- **ポップアップブロック**：クリックなどの操作なしで開くポップアップは止めて、右上に知らせます（「開く」「このサイトは常に許可」）
- **HTTPS優先**：http:// のページは https:// で開きます。対応していないサイトは警告を出し、「HTTPで開く」を選べます
- **広告とトラッカーのブロック**：EasyList / EasyPrivacy / uBlock Origin のリストで、広告や追跡用の通信を止めるほか、ページ内の広告枠を隠し、YouTube などの広告を外すスクリプトも動かします。鍵マークからサイトごとにオフにできます
  - YouTube：動画の情報から広告の予定を取り除き、動画の前や途中の広告を流さないようにします。万一流れたときは自動で飛ばし、ホームや検索結果の「スポンサー」枠も隠します
  - X（旧Twitter）：タイムラインの「プロモーション」投稿を取り除きます
  - リストは uBlock Origin・EasyList の配布元から12時間ごとに更新します
- **すばやく開く**：リンクにマウスを乗せたときや、アドレスバーに入力している間に、そのサイトへの接続を先に始めておきます。広告ブロックのリストの更新は別のプロセスで行うので、更新中もページが止まりません
- **トラッキングの拒否（GPC）**：サイトに「追跡しないで」と伝えます
- **シークレットタブ**（Ctrl+Shift+N）：履歴・Cookie・権限を保存せず、すべて閉じると消えます
- **ダウンロードの確認**：プログラムなど危険な種類や、クリックなしで始まったダウンロードは保存前に確認します。保存したファイルには「インターネットから来た」印を付けます（Windows）
- **外部アプリで開くリンク**（mailto: など）は、開く前に確認します
- ページはすべてサンドボックスで動き、ブラウザ本体の機能はWebサイトから使えません
- 利用状況の送信（テレメトリー）はしません。詳しくは 設定 → システム → プライバシーポリシー

## Chrome拡張機能
- 設定 → 拡張機能 →「Chromeウェブストアを開く」で、ウェブストアの「Chromeに追加」から追加できます（追加前に確認が出ます）
- 拡張機能のボタンはタイトルバーの右に並びます。押すとポップアップが開きます
- 設定 → 拡張機能 で、オプションを開いたり削除したりできます
- シークレットタブでは拡張機能は動きません
- Electron は Chrome の拡張機能の仕組みをすべては持っていないため、動かない拡張機能もあります（例：declarativeNetRequest を使う uBlock Origin Lite は効きません。広告ブロックは内蔵のものを使ってください）

## 言語（日本語 / English）
- 設定 → 一般 →「言語」で 日本語 / English / システムに合わせる を選べます。画面はすぐに切り替わります
- Webサイトに伝える言語（Accept-Language）は、次に起動したときに切り替わります

## 軽量化
- **タブの自動休止**：使っていないタブは30分（設定で変更可）で休止してメモリを空けます。音が鳴っているタブは休止しません
- 閉じたままのAIパネルも休止します
- 設定 → システム で、メモリ使用量の確認と「今すぐ休止」ができます

## 設定パネル（Ctrl+,）
- 一般：外観（ライト／ダーク／システム）、言語、検索エンジン、AI、起動時のタブ、既定のブラウザ、翻訳、幅
- パスワード：保存するか聞く、一覧・表示・削除、保存しないサイト、CSVの読み込み
- プライバシー：広告ブロック・HTTPS優先・GPC・履歴の保存、サイトの権限、例外にしたサイト、閲覧データの削除
- 履歴（Ctrl+H）：検索・削除
- プロフィール：名前の変更・追加・削除、ログイン情報を分ける、お気に入り
- 読み込み：ほかのブラウザのブックマーク・履歴、読み込んだブックマークの削除
- 拡張機能：一覧・オプション・削除、Chromeウェブストアを開く
- システム：タブの休止、メモリ、ダウンロードの保存先、バージョン・自動アップデート

## AIパネル
- 「要約」などのボタンで、開いているページの本文をAIの入力欄に貼り付けます（送信は自分で）
- AIパネルが設定したAI以外のサイトに移動しているときは送りません（⟳ で戻せます）
- クリップボードは使いません（入力欄が見つからなかったときだけコピーします。シークレットタブの内容はコピーしません）
- AIやボタンの中身は **config.js** で変更できます

## Claudeにログインできないとき
1. AIパネル上部の「タブで開く」ボタン（↗）でClaudeを大きなタブで開き、そこでログインします
2. メールでログインする場合は、メールのリンクを右クリック→リンクをコピーして、このブラウザのアドレスバーに貼り付けて開いてください
3. ログインできたら、AIパネルの ⟳ を押すとパネル側もログイン状態になります

# 一般公開するには

## 1. インストーラーを作る
- **自分のPCで作る**：「インストーラーを作る.bat」をダブルクリック → `dist\MyBrowser-Setup-0.3.0.exe` ができます
  - 「Cannot create symbolic link」で止まったら、Windowsの 設定 → システム → 開発者向け →「開発者モード」をオンにしてもう一度
- **GitHub で自動で作る**：リポジトリ `xelaods/my-browser` を作ってこのフォルダを push し、`v0.3.0` のようなタグを push すると、`.github/workflows/release.yml` がインストーラーを作って Releases に公開します

インストーラーは「ユーザーごとのインストール」（管理者権限なし）で、デスクトップとスタートメニューにショートカットを作り、「既定のブラウザ」の候補として Windows に登録します。

## 2. 自動アップデート
- インストール版は、GitHub Releases（`package.json` の `build.publish`）に新しいバージョンがあるか6時間ごとに確認し、ダウンロードして次の終了時に入れ替えます
- 新しいバージョンを出すとき：`package.json` の `version` を上げる → タグ（例 `v0.3.1`）を push

## 3. 公開前に決めること
- **名前とアイコン**：`package.json` の `productName` / `appId`、`build/icon.*`
- **コード署名**：署名していないインストーラーは、Windows SmartScreen で「WindowsによってPCが保護されました」と出ます（「詳細情報 → 実行」で進めます）。証明書を用意したら `release.yml` のコメントを外して `CSC_LINK` / `CSC_KEY_PASSWORD` を設定します
- **ライセンス**：今は `UNLICENSED`（非公開扱い）です。
  - **注意**：Chrome拡張機能に使っている electron-chrome-extensions は **GPL-3.0**（または有償の Patron ライセンス）です。このまま一般配布する場合は、ブラウザ全体を GPL-3.0 にしてソースを公開する必要があります。ソースを公開したくない場合は、有償ライセンスを買うか、拡張機能の対応（lib/extensions.js）を外してください
- **問い合わせ先**：`ui/privacy.html` の最後

## 4. 中の Chromium のバージョン
Electron 44（Chromium 152）を使っています。古い Chromium は脆弱性が残るうえ、X（旧Twitter）などで「自動操作のブラウザ」と判定されて reCAPTCHA が出やすくなります。Electron は数か月ごとに新しいバージョンが出るので、`package.json` の electron を上げて再ビルドしてください（サポートされるのは最新の3つのメジャーバージョンだけです）。

## 5. 配布版の安全設定（Electron Fuses）
`package.json` の `build.electronFuses` で、配布版では次のようにしています。
- Node.js としての起動・`NODE_OPTIONS`・デバッグ用の起動オプションを無効
- Cookie をOSの仕組みで暗号化
- アプリ本体（app.asar）の改ざんチェック、asar 以外からの読み込みを禁止
- `file://` の特別な権限を無効（ローカルのHTMLファイルが、ほかのファイルを読めないように）。ブラウザ自身の画面は `mb://ui/` で表示します

## データの保存場所
- インストール版：`%APPDATA%\MyBrowser`
- 開発版（npm start）：`%APPDATA%\my-browser`
- インストール版を初めて起動すると、開発版のタブ・お気に入り・設定・履歴を引き継ぎます（ログイン状態は暗号化の方式が違うため引き継ぎません）
